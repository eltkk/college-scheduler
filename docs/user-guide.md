# Инструкция составителю

1. Войдите под личным логином. Все четыре составителя видят общие данные и имеют одинаковые права.
2. В «Настройках» загрузите согласованные правила колледжа: пятидневка, пять пар с пятиминуткой, 36 часов с С/Р и отдельное ручное составление консультаций/аттестаций. Проверьте звонки, праздники, переходы и подтвердите сохранение. Особые недели можно явно исключить из обычного норматива. Изменение правил отклоняется, если существующее занятие им противоречит. Подробности: `docs/customer-rules.md`.
3. В «Справочниках» добавьте преподавателей, группы, предметы и места. Для подгруппы укажите родительскую группу. Для отдельного кабинета параллельных занятий обычно 1; для общей базы задайте реальный лимит и вместимость. Ограничьте доступные интервалы только там, где они известны.
4. В «Импорте» выберите «Семестровая нагрузка Word» и загрузите DOCX. Выберите таблицу, введите подтверждённые даты семестра. Раскройте ячейки, сверьте текст и назначения, выберите только проверенные. Укажите отдельные/совместные занятия групп и режим участия преподавателей. Часы получает каждая указанная группа целиком. Сложные часы вводятся вручную с пояснением; оставшиеся виды добавляются отдельными семестровыми записями. Для С/Р сохраните ответственного преподавателя и укажите, присутствует ли он на занятии. Проверьте новые группы, исправьте опечатки названий или используйте существующие справочники. Подтвердите сохранение.
5. Загрузите КУГ: выберите лист и недельный столбец, реальную дату понедельника и группы. Проверьте заголовки. Для каждой строки, включая С/Р, выберите семестровые назначения нужного вида, недельные часы каждого раздела, помещение и размер блока. Сумма для каждой группы должна совпадать с КУГ. Клиническое занятие 4 часа задайте блоком 4. У С/Р кабинет может отсутствовать; для обычных занятий обязателен. Разные преподаватели групп переносятся из назначений. Без семестровой связи нагрузка создаётся отдельно для каждой группы; общее занятие выбирается явно.
6. В «Нагрузке» есть недельный план и семестровые назначения. Недельную строку можно связать с семестровой записью при создании/редактировании. Часы недели задаются по КУГ, сумма связанных недель не может превысить часы периода. При изменении семестрового назначения можно явно выбрать обновление состава и преподавателей всех связанных недельных строк и занятий одной проверяемой операцией. При конфликтах изменения целиком отклоняются. Для недельного XLSX сопоставьте колонки; названия должны совпадать со справочниками, альтернативы разделяются `;`. Несовпадение часов с КУГ отклоняется. Список из нескольких преподавателей может означать выбор одного или совместное присутствие всех: режим указывается явно.
7. Выберите неделю и нажмите «Сформировать». Для общей лекции потока выберите всех участников. Консультации и аттестации сначала разместите вручную, если их часы нужны для этой недели: профиль не расставляет их автоматически. Если выбранная нагрузка с сохраняемыми занятиями не закрывает 36 часов каждой группы, исправьте план; недостающие часы не придумываются. Дождитесь результата, просмотрите назначения, нажмите «Применить вариант». Для двух недель подтвердите и сформируйте каждую неделю отдельно.
8. Занятие в сетке открывается кликом. Можно менять дату/время, преподавателя, помещение и примечание; связанное занятие должно соответствовать нагрузке. Ручная правка закреплена по умолчанию и сохранится при следующих расчётах. Снимите «Закрепить» только если разрешаете пересоставление. Обмен двух занятий выполняется одной проверкой и закрепляет обе позиции.
9. Нажмите «Проверить». Перед сдачей недели все подтверждённые часы должны быть размещены, предупреждения разрешены. Занятие «Вне плановой нагрузки» не закрывает часы КУГ.
10. «Excel» выгружает недельную сетку и сводку часов. В «Истории» хранятся последние 200 версий; можно восстановить всё состояние, включая справочники и нагрузку. Используйте это осознанно: откат касается работы всех четырёх составителей.

Если другой пользователь сохранил изменения, ваша правка старой версии отклоняется. Закройте/сохраните нужные введённые сведения, обновите данные и повторите правку на актуальной версии. Нельзя применить результат генерации, рассчитанный до последующих изменений данных.

Статус «за время решение не найдено» не означает невозможность расписания. Проверьте доступность, закрепления и размер выбранного состава. Статус несовместимых ограничений требует уточнения входных правил, часы нельзя молча уменьшать.
