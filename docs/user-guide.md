# Инструкция составителю

1. Войдите под личным логином. Все четыре составителя видят общие данные и имеют одинаковые права.
2. В «Настройках» укажите учебные дни, длительность академического часа, звонки, праздники и переходы. Подтвердите проверку. Изменение правил может быть отклонено, если существующее занятие им противоречит.
3. В «Справочниках» добавьте преподавателей, группы, предметы и места. Для подгруппы укажите родительскую группу. Для отдельного кабинета параллельных занятий обычно 1; для общей базы задайте реальный лимит и вместимость. Ограничьте доступные интервалы только там, где они известны.
4. В «Импорте» загрузите КУГ. Выберите лист и недельный столбец, укажите реальную дату понедельника и группы. Проверьте предупреждения в заголовках. Для строк назначьте преподавателя, помещение, вид и размер блока. Существующую дисциплину можно выбрать вместо создания по названию строки.
5. Теория выбранных групп станет общей нагрузкой. Практика будет создана отдельно для каждой группы. Для разных преподавателей практики после подтверждения измените назначения в «Нагрузке». Самостоятельная работа не создаёт пары.
6. Загрузите преподавательскую нагрузку либо уточните назначения в «Нагрузке». Для XLSX сопоставьте колонки, названия должны совпадать со справочниками. Несколько альтернатив разделяются `;`. Несовпадение часов с КУГ требует сверки, не исправляется автоматически.
7. Выберите неделю и нажмите «Сформировать». Для общей лекции потока выберите всех участников. Дождитесь результата, просмотрите назначения, нажмите «Применить вариант».
8. Занятие в сетке открывается кликом. Можно менять дату/время, преподавателя, помещение и примечание; связанное занятие должно соответствовать нагрузке. «Закрепить» сохраняет его при следующих расчётах. Обмен двух занятий выполняется одной проверкой.
9. Нажмите «Проверить». Перед сдачей недели все подтверждённые часы должны быть размещены, предупреждения разрешены. Занятие «Вне плановой нагрузки» не закрывает часы КУГ.
10. «Excel» выгружает недельную сетку и сводку часов. В «Истории» хранятся последние 200 версий; можно восстановить всё состояние, включая справочники и нагрузку. Используйте это осознанно: откат касается работы всех четырёх составителей.

Если другой пользователь сохранил изменения, ваша правка старой версии отклоняется. Закройте/сохраните нужные введённые сведения, обновите данные и повторите правку на актуальной версии. Нельзя применить результат генерации, рассчитанный до последующих изменений данных.

Статус «за время решение не найдено» не означает невозможность расписания. Проверьте доступность, закрепления и размер выбранного состава. Статус несовместимых ограничений требует уточнения входных правил, часы нельзя молча уменьшать.
